# Сортировщик фалов

### Общий функционал
Данное приложение предназначено для сортировки большого количества файлов по времени их создания.

Исходная директория, а также конечная директория настраиваются через файл application.properties.

Присутствует 2 стратегии сортировки:
* В зависимости от года создания (BY_YEAR). Сортирует файлы в папки, названные по году создания файлов.  
* В зависимости от года создания (BY_YEAR_AND_MONTH). Сортирует файлы в папки, названные по году создания файлов. Внутри папки года создаются папки для каждого месяца.

Также присутствует 2 стратегии переименования файла:
* По дате создания (RENAME_TO_CREATION_DATE). В процессе каждый файл переименовывается в дату формата "dd.MM.yyyy - HH.mm.ss". Удобно использовать в случае сортировки большого количества файлов с неинформативными названиями. 
* Без изменения названия (NO_RENAME). Название файла не изменяется.
